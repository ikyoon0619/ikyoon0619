### 안녕하세요, 윤인규입니다 👋

**LLM 서비스 개발자**로 일하고 싶어 준비하고 있습니다.
포스코와 LG화학에서 Salesforce CRM을 개발하면서 고객·영업 데이터와 사내 시스템 연동을 다뤘고, 지금은 그 경험을 살려 문서를 근거로 답하고 도구를 호출하는 상담 에이전트를 만들고 있습니다.
LLM 기능은 평가셋을 직접 만들어 숫자로 확인하면서 고칩니다.

🌐 **포트폴리오** https://portfolio-site-ikyoon.netlify.app

#### 대표 프로젝트 · AI 고객상담 에이전트

[코드](https://github.com/ikyoon0619/ai-cs-agent) · [데모](https://ai-cs-agent.onrender.com)

- 자동차 카탈로그 PDF를 근거로 답하고, 근거 페이지를 함께 보여 주는 RAG 상담 서비스
- 하이브리드 검색(BM25 + 벡터, RRF)으로 MRR 0.928 → 0.957 (직접 만든 평가셋 23문항 기준)
- Claude가 상황에 맞는 도구를 고르고(Tool Use) LangGraph로 흐름을 관리. 시승 예약처럼 실제로 실행되는 도구는 상담원이 승인해야 실행
- FastAPI · Streamlit, Render + Neon(pgvector)으로 배포, 하루 질문 수 제한
